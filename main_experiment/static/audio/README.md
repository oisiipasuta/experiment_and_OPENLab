# Audio Stimuli

音源ファイルは容量が大きく、研究素材や著作権管理が必要な場合もあるため、通常の Git 管理からは除外しています。

決定済みの曲リストに従って、次のフォルダに音源を配置してください。

| 配置先 | 曲数 | 用途 |
| --- | ---: | --- |
| `practice/` | 任意 | 練習試行 |
| `common/` | 15 | 全参加者に提示する共通曲 |
| `random_sets/1/train/` | 10 | セット1のランダム学習曲 |
| `random_sets/1/test/` | 5 | セット1のランダムテスト曲 |
| `random_sets/2/train/` | 10 | セット2のランダム学習曲 |
| `random_sets/2/test/` | 5 | セット2のランダムテスト曲 |
| `random_sets/3/train/` | 10 | セット3のランダム学習曲 |
| `random_sets/3/test/` | 5 | セット3のランダムテスト曲 |

3セット全体で共通15曲・ランダム学習30曲・ランダムテスト15曲です。
参加者には共通15曲と指定されたセットの学習10曲・テスト5曲、合計30曲を提示します。
`train/` はモデル学習用の区分で、練習試行の `practice/` とは異なります。
曲の区分は固定し、参加者ごとに本試行30曲の提示順をランダム化します。

配置後に `python -m flask --app app sync-songs` を実行してください。
`audio/` や `random_sets/<番号>/` の直下にある曲は本試行に使いません。
